# Payment Dashboard – Power BI Project

## Project Overview

Developed an interactive **Payment Dashboard** to analyse customer payment behaviour and identify trends across different generations, loan categories, and payment methods. The dashboard enables users to monitor payment patterns, customer demographics, and loan usage to support data-driven business decisions.

## Technologies Used

* Microsoft Excel (Data Cleaning & Preprocessing)
* Microsoft Power BI (Dashboard Development & Visualisation)
* Data Modelling in Power BI
* DAX Measures & Calculated Columns
* Data Source: Kaggle Dataset

## Dashboard Features

* Total number of payment users
* Generation-wise analysis (Gen Z, Millennials, Gen X, Baby Boomers)
* Loan type distribution and customer usage
* Payment method analysis
* Interactive slicers and filters
* KPI cards and dynamic charts
* Customer demographic insights

## Business Problem

Financial organisations need to understand customer payment behaviour, identify which generations use digital payments the most, and determine the popularity of different loan types. Without visual analytics, identifying these trends is time-consuming and difficult.

## Business Impact

* Helps businesses understand customer payment preferences.
* Supports targeted marketing campaigns for different age groups.
* Identifies the most frequently used loan categories.
* Improves decision-making using interactive visual reports.
* Enables faster analysis through real-time dashboard insights.

## Key Insights

* Identifies which generation (Gen Z, Millennials, Gen X, etc.) uses digital payments the most.
* Shows the total number of customers using payment services.
* Highlights the most popular loan types among customers.
* Analyses payment trends across different customer segments.
* Provides a clear overview of customer behaviour through interactive visualisations.
